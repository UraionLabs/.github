# Support

This is the organization-wide support guide for [Uraion Labs](https://github.com/UraionLabs). A repository may provide its own `SUPPORT.md`; use that file when it exists.

## GitHub issues

Use issues on the relevant repository for:

- Defects (use the bug report template)
- Feature requests (use the feature request template)
- Documentation errors in that repository

Search existing issues first. Include the repository, version or commit, and environment.

Do not use public issues for security reports. See [SECURITY.md](SECURITY.md).

## What GitHub issues are not for

- Product or partnership discussions
- Career inquiries
- General questions about Uraion Labs that are not tied to a public repository

For those, use the [contact form](https://uraionlabs.com/#contact).

## Public information

- Website: [uraionlabs.com](https://uraionlabs.com)
- Research: [uraionlabs.com/#research](https://uraionlabs.com/#research)
- Organization: [github.com/UraionLabs](https://github.com/UraionLabs)

Some projects are unreleased. If there is no public repository yet, the website is the source of public information.

## Conduct

Participation in issues, pull requests, and other GitHub spaces is covered by the [Code of Conduct](CODE_OF_CONDUCT.md).
