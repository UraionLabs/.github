# Uraion Labs brand assets

Logos for press, partners and integrations. Text is outlined, so no fonts are needed.

| File | Use |
| --- | --- |
| `uraion-mark.svg` | Primary mark: white U and lime speed lines on a Tangerine tile |
| `uraion-mark-ink.svg` | Mark on an ink tile, for light or busy backgrounds |
| `uraion-avatar.svg`, `uraion-avatar-1024.png` | Full-bleed square for avatars that apply their own mask |
| `uraion-labs-lockup-dark.svg` / `.png` | Mark + URAION/LABS for dark backgrounds |
| `uraion-labs-lockup-light.svg` / `.png` | Mark + URAION/LABS for light backgrounds |
| `uraion-wordmark-tangerine.svg` | URAION wordmark |

## Colour

| Name | Hex |
| --- | --- |
| Tangerine | `#EE5001` |
| Acid Lime | `#C8FD03` |
| White | `#FCFFFF` |
| Ink | `#0B0806` |

Type: Archivo (wide, heavy, uppercase) for display. JetBrains Mono for labels.

Please don't recolour, stretch or add effects to the mark. If you need a format
that isn't here, use the [contact form](https://uraionlabs.com/#contact).
